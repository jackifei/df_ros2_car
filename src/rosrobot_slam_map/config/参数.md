# slam_toolbox 参数详解（ROS 2 Jazzy, v2.8.5）

> 本文档整理 `slam_toolbox` 节点（版本 2.8.5）所有可配置参数，按功能分组说明，方便快速理解并调参。

---

## 🔧 基础框架与坐标系

| 参数 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `map_frame` | string | `map` | 全局地图的坐标系 |
| `odom_frame` | string | `odom` | 里程计坐标系 |
| `base_frame` | string | `base_footprint` | 机器人本体坐标系（激光雷达安装于此坐标系下） |
| `restamp_tf` | bool | `false` | 是否重新打时间戳修正 TF 延迟（用于回放 bag 时） |
| `transform_publish_period` | double | `0.02` | 发布 `map→odom` TF 的间隔（秒），0.02=50Hz |
| `transform_timeout` | double | `0.2` | TF 查询超时时间（秒） |
| `tf_buffer_duration` | double | `30.0` | TF 缓存保留时长（秒） |

---

## 📡 输入话题与传感器

| 参数 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `scan_topic` | string | `/scan` | 激光雷达话题名 |
| `max_laser_range` | double | `12.0` | 激光最大有效距离（米），超出此值的点被忽略 |
| `min_pass_through` | double | `0.15` | 最小通过距离（低于此值视为无效点） |
| `throttle_scans` | int | `1` | 扫描降采样倍数，1=不降采样，2=每隔一帧处理 |
| `use_scan_barycenter` | bool | `false` | 是否使用扫描质心替代原始点云（减少计算量） |
| `use_scan_matching` | bool | `true` | 是否启用扫描匹配（关闭后只靠里程计更新） |

---

## 🗺️ 地图参数

| 参数 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `resolution` | double | `0.05` | 地图分辨率（米/像素），越小越精细但内存越大 |
| `map_update_interval` | double | `3.0` | 全图更新间隔（秒），数值越大更新越慢 |
| `map_name` | string | `map` | 地图保存时的文件名前缀 |
| `map_file_name` | string | `map` | 加载/保存地图的文件名（不含后缀） |
| `map_start_at_dock` | bool | `false` | 是否从充电桩位置开始建图（配合 dock 检测） |
| `map_start_pose` | double[] | `[0.0, 0.0, 0.0]` | 起始位姿 [x, y, theta] |
| `occupancy_threshold` | double | `0.65` | 占据概率阈值，高于此标记为障碍物 |
| `use_map_saver` | bool | `true` | 是否启用地图保存服务 |

---

## 🏃 运动触发更新

| 参数 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `minimum_travel_distance` | double | `0.35` | 机器人移动多少米后才触发一次地图更新 |
| `minimum_travel_heading` | double | `0.52` | 机器人旋转多少弧度后才触发一次地图更新 |
| `minimum_time_interval` | double | `0.5` | 两次更新之间的最短时间间隔（秒） |
| `check_min_dist_and_heading_precisely` | bool | `false` | 是否精确检查最小位移/角度（避免跳过小运动） |

---

## 🔍 扫描匹配与相关性

| 参数 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `correlation_search_space_dimension` | double | `0.9` | 粗搜索空间尺寸（米×米） |
| `correlation_search_space_resolution` | double | `0.01` | 粗搜索步长（米） |
| `correlation_search_space_smear_deviation` | double | `0.03` | 模糊化标准差（平滑似然场） |
| `coarse_angle_resolution` | double | `0.0349` | 粗搜索角度分辨率（弧度≈2°） |
| `coarse_search_angle_offset` | double | `0.349` | 粗搜索角度范围偏移（弧度≈20°） |
| `fine_search_angle_offset` | double | `0.087` | 精搜索角度范围偏移（弧度≈5°） |
| `link_match_minimum_response_fine` | double | `0.45` | 帧间匹配最小响应值（低于此认为匹配失败） |
| `link_scan_maximum_distance` | double | `1.5` | 帧间匹配的最大搜索距离（米） |
| `use_response_expansion` | bool | `false` | 是否动态扩展响应阈值（自适应调整） |

## 🔁 闭环检测

| 参数 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `do_loop_closing` | bool | `true` | 是否启用闭环检测 |
| `loop_match_minimum_chain_size` | int | `10` | 闭环候选链的最小长度（帧数） |
| `loop_match_minimum_response_coarse` | double | `0.55` | 粗匹配阶段闭环最小响应值 |
| `loop_match_minimum_response_fine` | double | `0.75` | 精匹配阶段闭环最小响应值 |
| `loop_match_maximum_variance_coarse` | double | `3.0` | 粗匹配最大允许方差（控制匹配质量） |
| `loop_search_maximum_distance` | double | `7.5` | 闭环搜索半径（米） |
| `loop_search_space_dimension` | double | `8.0` | 闭环搜索空间尺寸（米×米） |
| `loop_search_space_resolution` | double | `0.025` | 闭环搜索步长（米） |
| `loop_search_space_smear_deviation` | double | `0.04` | 闭环搜索模糊化标准差 |

## ⚙️ 后端优化（Ceres Solver）

| 参数 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `solver_plugin` | string | `solver_plugins::CeresSolver` | 优化求解器插件（可选 `G2oSolver`） |
| `ceres_loss_function` | string | `None` | Ceres 损失函数（`HuberLoss`, `CauchyLoss` 等） |
| `ceres_linear_solver` | string | `sparse_normal_cholesky` | 线性求解器类型 |
| `ceres_preconditioner` | string | `SCHUR_JACOBI` | 预处理器 |
| `ceres_trust_strategy` | string | `LEVENBERG_MARQUARDT` | 信赖域策略 |
| `ceres_dogleg_type` | string | `TRADITIONAL_DOGLEG` | Dogleg 类型（仅当 trust_strategy=DOGLEG 时有效） |
| `angle_variance_penalty` | double | `0.0001` | 角度误差惩罚权重 |
| `distance_variance_penalty` | double | `0.001` | 距离误差惩罚权重 |
| `minimum_angle_penalty` | double | `0.001` | 最小角度惩罚项 |
| `minimum_distance_penalty` | double | `0.001` | 最小距离惩罚项 |
| `position_covariance_scale` | double | `1e-9` | 位置协方差缩放因子 |
| `yaw_covariance_scale` | double | `1e-9` | 偏航角协方差缩放因子 |

## 💡 常用调参建议

| 现象 | 建议调整的参数 |
|---|---|
| **地图漂移** | 降低 `minimum_travel_distance`、`minimum_travel_heading`；提高 `link_match_minimum_response_fine` |
| **建图速度慢** | 增大 `throttle_scans`、`map_update_interval`；降低 `correlation_search_space_resolution` |
| **闭环失败** | 增大 `loop_search_maximum_distance`；降低 `loop_match_minimum_response_fine`；确保 `do_loop_closing=true` |
| **地图模糊/噪声多** | 降低 `max_laser_range`；提高 `occupancy_threshold`；增大 `minimum_time_interval` |
| **小空间建图精度差** | 降低 `resolution`（如 0.02）；降低 `correlation_search_space_resolution` |
